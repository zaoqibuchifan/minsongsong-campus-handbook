# 民小松 · 校园手册问答助手

基于学生手册的**可查证**问答悬浮助手，挂载于个人网站「潘宇航 | 暮色列车」。
是《人工智能概论（B）》实践作业「任务一：校园手册问答助手」的网页实现。

## 它解决什么问题

校园制度问答最怕的不是"答不上来"，而是**编造**——把常识、别校规定、
网络传言当成本校制度输出。民小松的设计核心是三条：

1. **每句结论都能回到条款**：回答末尾标注「依据：《手册名》第 X 条」。
2. **两校条款严格隔离**：同时收录两所学校手册，按学校分册检索，绝不混用。
3. **没有依据就明说**：检索命中不足时如实告知"未查询到"，并给出咨询部门，
   不推测、不补全。

## 功能

| 功能 | 说明 |
|---|---|
| 悬浮气泡 | 右下角 IP 图标，点击展开；带未读提示点与引导语 |
| 学校切换 | 面板顶部两个按钮切换口径，**默认中南民族大学** |
| 默认口径声明 | 每次作答开头声明依据哪本手册 |
| 原文作答 | 输出手册原文分点，附条款依据，不做主观解读 |
| 无依据拒答 | 命中不足时说明未查到并建议咨询部门 |
| 诱导拦截 | 问"编个请假理由"时拒答，并引出手册中的违纪条款 |
| 越界拒答 | 心理咨询、法律判断、职业规划等一律礼貌拒绝 |
| 快捷问法 | 按学校提供 4 个高频问题胶囊 |
| 响应式 | 桌面端 380×560 悬浮窗，手机端自动全屏 |

## 本地运行

纯静态站点，任选一种：

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

然后访问 `http://localhost:8000`。

## 配置

在页面引入脚本前设置 `window.MINSONGSONG_CONFIG`：

```html
<script>
  window.MINSONGSONG_CONFIG = {
    school: 'scuec',                        // 默认口径：scuec / hust
    avatar: 'assets/minsongsong.jpg',       // 气泡头像
    hint:   '我是民小松，学生手册的事问我～'   // 引导语
  };
</script>
```

## 接入方式

在任意页面 `</body>` 前插入：

```html
<link rel="stylesheet" href="minsongsong.css">
<script>window.MINSONGSONG_CONFIG = { school: 'scuec' };</script>
<script src="minsongsong-kb.js"></script>
<script src="minsongsong-kb-hust.js"></script>
<script src="minsongsong.js"></script>
```

## 扩展知识库

往分册文件里加一条即可，字段约定：

```js
'your-key': {
  id: 'your-key',
  school: '中南民族大学',
  category: '请假与考勤',
  type: '流程类',                   // 流程类 / 材料类 / 条件类
  title: '条目标题',
  keywords: ['关键词1', '关键词2'],  // 命中权重 = max(2, 词长/2)
  answer: ['第 1 点', '第 2 点'],
  source: '中南民族大学生手册 ·《某办法》第 X 条'
}
```

关键词写得越接近学生的真实问法，命中率越高。

## 已知边界

- 前端为**关键词匹配**，非语义向量检索：问法差异过大可能漏召回，
  此时助手会如实告知未查到（不会编造），可换种说法或补充关键词。
- 知识库为**节选高频事项**，未覆盖手册全部条款。
- 制度以学校最新正式发文为准，助手内容仅供办理参考。
